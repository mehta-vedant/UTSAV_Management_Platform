Flagship feature, explained simply

Evidence-backed expenses and explainable planning.

The goal is not “AI for the sake of AI.” The goal is to give a committee evidence for an expense, controlled access to that evidence, and a clearer view of its recorded budget.

If S3 cannot accept a file, the expense remains saved and the receipt record becomes pending/failed. UTSAV does not use Vercel’s temporary disk and never pretends that a bill was stored.

2. Who can see the bill?

The uploader can see their own receipt. Treasurer and Admin can review receipts for the organization. A URL is never enough: server code checks the signed-in session, OrganizationMember, role permission, and organization id before it creates a short-lived view URL. Public transparency pages never expose bill files.

Gemini may suggest vendor, amount, date, category, receipt number, and summary. It cannot approve an expense or silently overwrite finance data. If it fails, the receipt remains available and the person enters details manually.

4. Budget Health is not guessing

The server calculates approved donations, approved spending, pending commitments, category totals, event totals, time remaining, and recent spending pace. It then creates cautious, expected, and ambitious scenarios from stated assumptions. Gemini can explain those facts in plain English, but it is not allowed to invent numbers or make a decision.

Interview answer

“I moved beyond CRUD by treating an expense as evidence-backed workflow data. Files are private S3 objects; PostgreSQL keeps relational metadata and audit history. AI is constrained: it suggests values from a consented receipt and explains deterministic budget scenarios, but all financial changes remain explicit human actions.”

Counter-questions

Why not store image files in PostgreSQL?

Large files make database backups, queries, and storage growth harder. PostgreSQL is best for connected structured records; S3 is designed for durable objects. The database keeps the link, owner, status, and audit trail.

What happens if S3 or Gemini is down?

S3 failure leaves a visible pending/failed receipt state and supports retry. Gemini failure never destroys the upload or blocks manual entry. Both are examples of graceful degradation.

Why does the planner not approve a budget?

A forecast is uncertain and financial decisions need accountability. The planner is read-only advice with cited assumptions; existing role-protected controls perform real changes.
