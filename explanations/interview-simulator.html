Five-minute flagship script

Problem: UTSAV gives festival and club committees one private workspace instead of chats, spreadsheets, and paper records.

Core design: It is a Next.js modular monolith. Server actions call services, services enforce membership and role permissions, Prisma stores connected records in PostgreSQL, SES sends identity emails, and private S3 stores receipt files.

Flagship workflow: An expense is no longer just a row. A member can attach private evidence. The server authorizes them, creates a short-lived S3 upload permission, confirms the object, and stores only metadata and audit history in PostgreSQL. Treasurer/Admin can review it; public pages cannot.

AI: Gemini is advisory only. With visible consent it suggests receipt fields for human review. Budget Health uses deterministic server calculations and Gemini only explains the resulting facts. It never approves or changes financial data.

Honest limitation: The current system is not a double-entry ledger. Next I would add idempotency to every financial mutation, then monitoring, backups, and a ledger if accounting requirements grow.
